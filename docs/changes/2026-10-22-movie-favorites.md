# 影片收藏入口与持久化

## 原因

用户反馈没有收藏按钮。原收藏仅针对直播频道，影片详情与播放页缺少对应入口。

## 变更与决策

- 在影片详情、独立播放窗口提供明确的收藏/取消收藏按钮，收藏页同时呈现影片和直播频道。
- 新增 `MovieFavoritesStore`，通过稳定影片 ID 识别搜索摘要与详情，保留站源、影片 ID、详情入口及线路信息；同名不同站点分别收藏。
- 影片收藏保存到本机 Application Support 下的 `TVBoxMacOS/movie-favorites.json`；不改变已有直播收藏格式。
- 原子保存成功后再更新界面；读取损坏文件时保留原文件，保存失败时维持原收藏状态并显示错误。

## 验证

- `swift test --filter MovieFavoritesStoreTests`：3 项通过，覆盖持久化与站源信息、详情更新与取消、损坏文件保护、保存失败状态。
- 界面集成和整体验证结果见本次任务最终验收记录。

## 风险与回滚

- 收藏记录保留原站源信息，站源失效时仍需更新站源或更换线路；收藏不是离线缓存。
- 回滚本次界面和新存储类即可，独立收藏文件可保留，不影响原有直播收藏。
