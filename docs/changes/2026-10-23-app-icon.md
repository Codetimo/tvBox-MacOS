# 更换银白陶瓷 APP 图标

## 原因与改动

用户选定银白陶瓷播放图标，要求替换软件图标。

- 将用户提供的原图保存为 `Resources/AppIcon.png`，SHA-256 与附件一致，保留原图构图和白色背景。
- 打包脚本使用 macOS 自带的 `sips` 和 `iconutil` 生成 16、32、128、256、512 点及对应 Retina 尺寸的 `AppIcon.icns`，写入应用资源目录。
- `Info.plist` 增加 `CFBundleIconFile`。图标随每次打包自动生成，临时 iconset 随现有 staging 目录清理，不引入第三方依赖。
- 继续仅替换 `~/Applications/TVBoxMacOS.app`，不创建额外 APP 或 ZIP。

## 验证

- `bash -n scripts/package_app.sh` 与 `git diff --check` 通过。
- 实际执行 `scripts/package_app.sh`：Release 构建、Bridge 构建、图标生成、签名及替换安装成功。Bridge 编译仍有现有 Java 8 引导类路径/过时 API 警告。
- 安装后的 `Info.plist` 校验及 `codesign --verify --deep --strict` 通过；从 ICNS 解包检查全部 10 个图标规格，尺寸正确。
- 刷新 Launch Services 注册并启动应用，核实运行路径为 `/Users/jackstrak/Applications/TVBoxMacOS.app`。导出正在运行应用的系统图标并目视核对，已为选定的银白图标。
- 安装目录只有一份 `TVBoxMacOS.app`，项目 `dist/` 无 APP 副本，打包临时目录已清理。
- 提交前补充验证：`swift test` 全部 168 项通过，0 失败；重新运行脚本中的图标生成步骤并解包核对，10 个规格尺寸正确；`bash -n` 与 `git diff --check` 通过。未重新验证真实站源播放功能。

## 风险与回滚

原图是不透明图片，白色背景按用户选择保留。若需要重新设计透明边缘，应另行处理图标资产。

需要回滚时撤销图标资产和打包脚本对应改动，再重新打包替换固定安装路径；不保留额外可启动备份。
