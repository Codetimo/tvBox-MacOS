# 跳转进度后的音画同步修复

## 原因与复现

兼容播放使用 FFmpeg 输入 `-ss`、视频 stream copy 和音频 AAC 重编码。默认 accurate seek 只裁掉重编码音频的前置内容，视频却保留请求位置之前的关键帧。在带 AAC、B 帧和 10 秒 GOP 的本地 MKV 上跳转 7.3 秒，旧命令实际解码视频首帧为 0 秒、音频首帧为 7.257 秒，存在秒级起点差异。旧时间轴也把请求时间直接当作关键帧位置，进度显示与实际内容可能不符。

## 修改与决策

- 输入定位增加 `-noaccurate_seek`，让复制视频和重编码音频保留同一段关键帧前置数据。保留源时间戳并归一化原始起点，不对两条轨道分别重置时间。
- 从 FFmpeg 输出的 `init.mp4` 音视频 edit list 读取最早的共同源起点；全部轨道统一减去这一偏移并原子改写 init，保留音画相对延迟，避免把原片偏移当作播放片段前的空白。解析器验证层级、长度、版本和整数边界，只读取本次会话的元数据。
- AVPlayer 就绪后先完成精确跳转，再按原暂停/播放状态恢复，时间轴采用实际关键帧偏移。继续复制视频，无视频重编码成本。
- 缓存内和普通原生 seek 使用零容差、取消旧请求和请求标识校验；连续方向键按最新待完成目标累加，旧回调不能覆盖新请求。
- WebKit 播放视图销毁时暂停网页媒体、停止加载并清空页面，避免关闭新播放窗口后残留声音。

## 验证

执行 `swift test --filter 'MP4CompatibilityTests|PlaybackSeekTests|MediaCompatibilityTests|RemuxTimelineTests|PlaybackTests'`，28 项通过、0 失败、0 跳过（约 14.6 秒）；本机 FFmpeg 已安装，真实媒体测试实际执行。

新增真实媒体覆盖：AAC、B 帧、10 秒 GOP、非关键帧目标、原始时间戳偏移 5 秒；FFmpeg 解码首音视频时间差小于 150ms。AVPlayer 从约 60 秒的关键帧附近出发，精确落到原片 63.3 秒，连续缓存跳转最终落到 66.3 秒。保留既有跨缓存跳转、暂停/音量、取消过期会话和停止清理测试。新增 32/64 位 edit list、截断和错误元数据测试。

## 边界与回滚

本地合成媒体和实际 AVPlayer 异步定位已验证；未声称所有远端供应商、特殊长 GOP、真实人物口型或外接音频设备已人工验收。超过首分片准备超时的异常线路仍需切换。回滚时一起撤销保留源时间戳、edit list 时间轴和初始精确 seek，避免只回滚一侧导致偏移错误。保留工作区原有 HEVC/MP4 探测和请求头兼容修改。

## 后续补充：直播 TLS 错误反馈

`playbackFailureMessage` 识别直接及包装在 `NSUnderlyingErrorKey` 的 TLS/证书错误，明确提示安全连接失败的可能原因（证书、上游 TLS、代理链路），建议切换线路或检查系统时间、代理连接；不关闭证书验证，不展示源 URL。错误码显示实际 URL 层错误。`swift test --filter PlaybackTests`：6 项通过、0 跳过；包含直接和包装 TLS 错误及敏感 URL 脱敏回归。

代码复核关闭路径：独立播放窗口先调用 `playback.stop()` 暂停唯一 AVPlayer，再移除内容；`NativePlayerView.dismantleNSView` 关闭全屏窗口并解绑视图。普通退出全屏继续原窗口播放，关闭整个播放窗口停止播放。此处为生命周期代码复核，未声称已人工听音验收。

## 集成补充：HEVC 时间轴及幂等清理

最终 28 项组合全部通过。HEVC 回归验证同时检查 HLS `EXTINF` 总长为 4 秒、外部源偏移为 4 秒、归零后的 fMP4 有效时长为 4 秒；AVFoundation 零容差在局部 1 秒解码出真实 320×180 HEVC 帧。AVPlayer 挂载视频输出后必须完成 HLS 局部 1 秒精确跳转（对应原片 5 秒），取得像素缓冲，并继续推进播放时间。不能只修改时长期望值或仅观察 `currentTime` 就视为实际解码通过。

媒体会话停止改为幂等；存活 FFmpeg 由终止回调删除目录，避免 `stop`、`deinit` 和终止回调并发重复删除同一目录。
