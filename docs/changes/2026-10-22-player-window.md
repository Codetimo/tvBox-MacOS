# 2026-10-22 独立播放窗口

## 原因与行为

播放入口此前将主窗口切换到“正在播放”页，不能在独立窗口观看并继续浏览。现在点击影片、剧集或直播播放时打开同一个独立播放窗口，主窗口保留原浏览位置；搜索提交则进入影视结果页。

## 主要改动与决策

- 新增 `PlaybackWindowController`，统一管理窗口与解析任务，复用现有 `PlaybackCoordinator`。连续播放、换线路、换集复用同一窗口，避免多个播放器同时发声。
- 原播放页完整迁入窗口，保留原生/网页播放、解析中提示、错误与重试、平铺线路/选集，以及影片收藏按钮。
- 直播窗口显示频道名称与分组，提供显式收藏/取消收藏；播放失败显示“重试直播”，与频道卡片复用同一播放入口。关闭窗口同时清空当前频道。
- 关闭播放窗口取消待完成的解析并停止播放，释放内容；再次点击播放可重新建窗。
- 主浏览窗口使用 SwiftUI 单实例 `Window`，避免新建多个主窗口分别持有播放器。
- 顶栏接入本地搜索建议组件，搜索历史/影片结果/频道/分组提供补全；为建议下拉设置显示层级并提供清空历史入口。搜索模块详见对应记录。
- 收藏影片入口位于卡片、详情与播放窗口，收藏页同时展示影片和原有直播频道；收藏持久化详见对应记录。

## 验证

- `swift test --filter PlaybackWindowTests`：3 项通过。覆盖重复播放复用窗口、关闭取消任务并只停止一次、关闭后重新打开及旧内容释放；该命令也编译了应用与所有测试代码。
- 本机真实 UI 验收：CGTN英语（央视IPV4）打开独立窗口，主窗口保留直播页；计时推进且截图确认实际视频画面。关闭后窗口消失。
- 影片收藏通过“结果卡片 → 收藏页 → 重启 → 详情 → 播放窗口”验证持久化及同步；详情与播放窗口的取消收藏均同步到主窗口。验收新增收藏已清除。
- 搜索建议已验证上下键、回车补全、Escape 关闭，以及真实鼠标点击历史建议后补全并发起搜索。
- 第三方边界：暴风《一人之下 第六季》第1集返回 `NSURLErrorDomain (-1100)`，窗口正常展示错误、重新解析与选集入口；该片源实际播放未通过。音画同步的媒体验证见对应记录。

## 风险与回滚

- 第三方网页线路仍由 WebKit 承载，网络/授权限制不因拆分窗口改变。
- 原“播放页搜索结束返回影视页”改为搜索提交直接展示结果，原因是主窗口已不再承载播放页。
- 可回退本次窗口控制器及视图迁移恢复内置播放页；不涉及站源、账户凭据迁移。
