# 全屏播放器控制栏空闲自动隐藏

> 后续用户要求只保留一个 APP。本记录中的多目录部署、备份和日期 ZIP 已由 `2026-10-22-single-app-packaging.md` 替代，相关旧产物已清理；当前入口为 `~/Applications/TVBoxMacOS.app`。

## 原因与变更

自定义播放控制栏始终可见，影响全屏观看。本次修改 `Playback.swift`：进入独立全屏窗口后，约 3 秒无鼠标或键盘操作时隐藏整组底部控件，包括进度、缓存、音量、时间和播放按钮；在该窗口移动/点击/拖动鼠标、滚动或操作键盘时立即恢复显示并重新计时。

## 关键决策

- 复用现有 0.25 秒控件刷新定时器，使用单调时钟计算空闲时间；实际隐藏在约 3～3.25 秒发生。
- 事件监听仅匹配当前全屏窗口，并原样返回事件，保留按钮、滑块和快捷键行为。
- 进度或音量滑块按住期间保持可见；松开后重新计算空闲时间。
- 全屏动画完成后启动计时，退出全屏、关闭窗口、移除视图或释放对象时清理监听。普通窗口的控件保持显示。
- 普通播放与兼容播放共用此逻辑；播放状态/时间轴刷新不会唤醒控制栏，暂停时也可自动隐藏。
