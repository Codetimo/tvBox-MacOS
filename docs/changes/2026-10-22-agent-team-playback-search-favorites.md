## 集成验证

- 最终 `swift test`：133 项通过、0 失败，约 31 秒；无 XCTest 跳过。本机 FFmpeg 可用，MKV/HEVC 实际解码测试执行。
- 媒体定向测试覆盖 HEVC 精确 seek 完成、真实像素缓冲及播放时间推进；带音轨 MKV 的非关键帧定位、连续跳转和两轨统一时间轴。合成媒体音视频解码起点差小于 150ms，不等同于人工口型验收。
- 真实直播：CCTV1、CGTN 英语、苏州 4K 均由 AVPlayer 取得视频帧且时间推进。CGTN 在独立窗口显示实际画面，主窗口仍保留直播浏览；关闭窗口后仅剩主窗口。
- 搜索：实际上下键选择、回车补全搜索、Escape 收起通过；正式应用鼠标点击影片历史候选能补全输入并开始搜索，未出现失焦吞点击。中文输入法组合候选未逐种人工验证。
- 收藏：影片结果、详情、播放窗口与收藏页状态同步；重启后影片收藏保留。验收临时新增收藏已清除。原有 307 个频道的重复 ID 已迁移成 307 个唯一 ID，源地址和频道地址不变；另一来源目录由 4 个错误占位恢复为 222 个频道。
- 新增推荐按来源导航：频道与分组进入直播筛选，影片与历史进入影视搜索；普通回车仍使用搜索入口。
- 最终正式应用验收：鼠标点击“CGTN英语 · 频道”建议从首页进入直播筛选，仅显示 2 个同名频道且不触发影视搜索；收藏央视 IPv4 的 CGTN 后，收藏页正确显示 CGTN，不再错成 CCTV1。播放窗口再次打开后取得真实新闻画面，进度从 00:00 推进至 00:45。随后关闭测试播放窗口、取消临时收藏，保留正式应用主窗口运行。

## 部署与回滚方式

使用 `scripts/package_app.sh` 替换唯一安装路径 `~/Applications/TVBoxMacOS.app`，固定 ZIP 为 `dist/TVBoxMacOS-macOS-arm64.zip`，不保留额外 APP 或日期发布目录。回滚代码须按分项记录撤销相互依赖的时间轴逻辑；源库迁移保留所有真实频道及用户源配置，影片收藏使用独立本机文件。

最终发布核对：`codesign --verify --deep --strict` 通过，ZIP 完整性通过、ZIP 内可执行文件与已安装 APP 的 SHA-256 一致；`dist/` 中 APP 数为 0。旧备份与 debug 进程已退出，仅从固定安装路径启动新版。最终已安装可执行文件 SHA-256 为 `eaa5d3b1367eb4a7b77af45b1eb93d4145e5c98adc347ff96d3c51593fc4094f`。
