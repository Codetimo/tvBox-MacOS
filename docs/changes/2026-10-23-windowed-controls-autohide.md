# 小屏播放器也自动隐藏控制栏

## 原因与修改

此前只有独立全屏窗口启用控件自动隐藏。用户要求普通小屏播放也具有相同行为。

- `KeyboardPlayerView` 加入窗口时自动开启空闲计时，小屏和全屏统一约 3 秒无操作隐藏整组进度、音量、时间与播放按钮。
- 鼠标在播放器画面内活动，或播放器/内部控件持有键盘焦点时操作键盘，重新显示并计时。搜索框、选集区域和其他窗口的输入不唤醒控制栏。
- 同时检查 `bounds` 和 `visibleRect`：新版 AppKit 在不裁剪子视图时，`visibleRect` 可能超出播放器自身范围，单独使用它会误判画面外的操作。
- 拖动滑块时保持显示；视图移除和全屏关闭时继续清理监听。退出全屏返回小屏后，先显示控件，再重新计时。
- 不修改播放错误提示、媒体解析或资源地址处理。

## 验证

- `swift test`：168 项通过，0 失败，无跳过。覆盖小屏挂载自动隐藏、鼠标/键盘唤醒、同窗口播放器外的事件隔离、文本编辑焦点隔离、视图移除清理等。日志：`/tmp/tvbox-windowed-autohide-all-tests.log`。
- 从当前源码提取原样播放器类，用本地测试视频验证实际 AppKit 小屏与系统全屏：小屏空闲隐藏、鼠标和键盘唤醒、全屏隐藏与鼠标唤醒、Esc 返回相同播放器、小屏再次隐藏均已观察到。媒体在小屏控件隐藏时继续播放，切换后时间进度保留。
- 系统级 UI 脚本的首次固定时间隐藏断言未通过，后续再次隐藏、鼠标/键盘唤醒及全屏切换断言通过；实际鼠标活动和主线程任务延迟会影响定时断言。截图检查另外等待实际空闲状态，并使用明确窗口坐标的 AppKit 合成鼠标事件验证显示，避免系统级合成事件投递不稳定；该截图验证不等同于人工操作验收。没有因此调整产品的 3 秒超时。记录：`/tmp/tvbox-windowed-autohide-ui.log`、`/tmp/tvbox-windowed-autohide-visual.log`。
- 本次使用本地媒体验证控件，没有重新验证外部站源播放、搜索或详情，也没有把截图中的资源加载错误作为本次修复目标。
- `scripts/package_app.sh`：Release 构建、Bridge 重建、签名和固定路径替换成功；`codesign --verify --deep --strict`、ZIP 完整性校验及 `git diff --check` 通过。
