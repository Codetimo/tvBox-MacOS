# 搜索内容推荐补全

## 原因与内容

顶部搜索框原先只能手动输入完整关键词。新增本地候选引擎、历史存储和搜索输入组件：

- 合并搜索历史、当前已加载影片、频道、频道分组，标明建议来源。
- 完整匹配优先，其次前缀和包含匹配；忽略大小写、全半角及首尾空白并去重，最多显示 8 项。
- 搜索提交时记录最多 30 条本机历史，重复关键词前移；空输入仅展示历史，支持清空历史。
- 点击建议或上下键选择后回车补全，并按候选来源处理：频道/分组进入直播筛选，影片/历史执行影视搜索；未选择建议时回车提交原输入，Escape 收起建议。
- 通过 NSTextField 代理兼容 macOS 13 的键盘操作，中文输入法组合文本期间交由输入法处理。

## 关键决策

建议完全来自本机历史和已经加载的数据，输入过程不调用网络接口。仍通过原有搜索入口执行用户明确提交的搜索；不会每输入一个字就查询全部站源。未加载的影片不会凭空产生建议。

## 验证

- `swift test --filter SearchSuggestionTests`：6 项测试通过，0 失败，覆盖排序、跨来源去重、全半角/大小写、空查询、候选限制、历史持久化、重复前移、容量与清理。
- 上述命令编译了完整应用和测试目标。
- 原生界面的点击、上下键、中文输入法交互尚需实际窗口验证；单元测试不等同于 UI 验收。

## 风险与回滚

历史只写入 `UserDefaults` 的 `TVBoxMacOS.searchHistory` 键。回滚时还原顶部搜索框接入并删除新增组件/模型即可；不影响站源配置、播放记录或 Cookie。
